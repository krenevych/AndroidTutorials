# Завдання: Простий Калькулятор (View Approach)

## Мета завдання
Закріпити навички побудови інтерфейсу користувача за допомогою XML-розмітки (View Approach) та роботи з обробниками подій в Kotlin з використанням `ViewBinding`. 

Ви створите простий калькулятор, який вміє виконувати 4 базові математичні операції з двома числами.

## Вимоги до інтерфейсу (UI)
Ваш застосунок має містити наступні елементи на екрані (в `activity_main.xml`):

1. **Два поля вводу (EditText):**
   * Перше поле для введення першого числа.
   * Друге поле для введення другого числа.
   * *Порада:* Щоб користувач міг вводити тільки числа, використовуйте атрибут `android:inputType="numberDecimal"` для обох полів.
2. **Чотири кнопки (Button):**
   * Кнопка "+" (Додавання)
   * Кнопка "-" (Віднімання)
   * Кнопка "*" (Множення)
   * Кнопка "/" (Ділення)
   * *Порада:* Ви можете розмістити ці кнопки горизонтально в один ряд, використовуючи `LinearLayout` з атрибутом `android:orientation="horizontal"`.
3. **Текстове поле (TextView):**
   * Для відображення результату обчислення або повідомлення про помилку.

## Технічні вимоги (Логіка)

1. Проект повинен використовувати **ViewBinding** (не використовуйте `findViewById`).
2. Коли користувач натискає на одну з кнопок операцій (+, -, *, /):
   * Програма має зчитати значення з обох `EditText`.
   * Перевірити, чи обидва поля не є порожніми. Якщо хоча б одне поле порожнє, виведіть повідомлення в `TextView`, наприклад: *"Будь ласка, введіть обидва числа"*.
   * Перетворити введений текст (String) у числа (наприклад, у тип `Double`).
   * Виконати відповідну математичну операцію.
   * Вивести результат у `TextView` у форматі: *"Результат: [число]"*.
3. **Обробка ділення на нуль:**
   * Якщо користувач намагається поділити на нуль (натиснув кнопку "/", а друге число дорівнює `0`), програма не повинна впасти. 
   * Виведіть повідомлення про помилку в `TextView`: *"Помилка: ділення на нуль неможливе!"*.
4. **Логування:**
   * Додайте логування за допомогою класу `Log`. Виводьте в консоль `Logcat` повідомлення при натисканні на будь-яку кнопку (яка операція виконується та з якими числами). Використовуйте рівень `Log.d`.
   * Якщо сталася помилка (ділення на нуль або порожні поля) — виводьте `Log.w` (Warning).

## Додаткове завдання (із зірочкою ⭐)
* Зробіть так, щоб результат виводився без зайвих нулів після коми, якщо число ціле (тобто `5.0` виводилось як `5`, а `5.5` як `5.5`).
* Додайте ще одну кнопку "Очистити" (Clear), яка буде стирати текст в обох `EditText` та скидати результат в `TextView`.
