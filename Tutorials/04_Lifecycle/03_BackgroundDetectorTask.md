# Завдання: Створення BackgroundDetector

## Мета завдання
Навчитися відстежувати загальний стан застосунку (чи він активний на екрані, чи згорнутий у фоні), незважаючи на те, яка саме Activity зараз відкрита. 
Для цього ви створите клас-утиліту `BackgroundDetector`, ініціалізуєте його у вашому `Application` класі та навчитеся взаємодіяти з ним з будь-якого екрану.

## Навіщо це потрібно?
Коли у вас одна Activity, легко зрозуміти, коли програму згорнули (спрацьовує `onStop`). Але якщо у вас 5 екранів, перехід між ними також викликає `onStop` для старого екрану. Як зрозуміти: користувач просто перейшов на інший екран всередині вашої програми, чи він повністю згорнув ваш застосунок (натиснув кнопку Home)?

Для цього використовують спеціальний колбек `ActivityLifecycleCallbacks`, який реєструється на рівні класу `Application` і "слухає" події **всіх** Activity вашого застосунку.

## Частина 1: Створення BackgroundDetector

1. **Створення класу:**
   У вашому проекті створіть новий Kotlin-клас з назвою `BackgroundDetector`. 
   Він повинен реалізовувати інтерфейс `Application.ActivityLifecycleCallbacks`. 

2. **Логіка підрахунку:**
   * Створіть всередині класу лічильник: `private var activeActivitiesCount = 0`
   * Коли будь-яка Activity запускається (виклик `onActivityStarted`), збільшуйте лічильник на `1`.
   * Коли будь-яка Activity зупиняється (виклик `onActivityStopped`), зменшуйте лічильник на `1`.

3. **Ознака фонового режиму:**
   * Створіть публічну властивість (або функцію) `val isAppInBackground: Boolean`, яка повертає `true`, якщо `activeActivitiesCount == 0`, і `false` у протилежному випадку.
   * *Пояснення:* Якщо лічильник дорівнює нулю, значить жодна Activity зараз не видима на екрані, отже весь застосунок знаходиться у фоні!

4. **Логування:**
   У методах `onActivityStarted` та `onActivityStopped` додайте логування (через `Log.d` або `Timber`), яке буде виводити:
   * Назву Activity, яка змінила стан (можна отримати через `activity.javaClass.simpleName`).
   * Поточну кількість активних екранів (`activeActivitiesCount`).
   * Поточний статус програми (Фон чи Foreground).

*(Зауваження: В інтерфейсі `ActivityLifecycleCallbacks` багато методів, які вам доведеться "перевизначити" (`override`). Ви можете залишити більшість із них порожніми, нас цікавлять лише `onActivityStarted` та `onActivityStopped`).*

## Частина 2: Ініціалізація в Application

Щоб ваш `BackgroundDetector` почав слухати події, його треба зареєструвати в класі `Application`.

1. Відкрийте ваш кастомний клас `MyApp` (який ви створили у попередньому завданні).
2. Створіть властивість для детектора:
   ```kotlin
   val backgroundDetector = BackgroundDetector()
   ```
3. У методі `onCreate()` вашого `MyApp` зареєструйте його за допомогою стандартної функції:
   ```kotlin
   registerActivityLifecycleCallbacks(backgroundDetector)
   ```

## Частина 3: Перевірка статусу з Activity

Тепер ми можемо з будь-якої Activity дізнатися, чи ми (як застосунок в цілому) активні.

1. У вашій `MainActivity` додайте кнопку (наприклад, `btnCheckStatus`).
2. В обробнику натискання (`setOnClickListener`) отримайте доступ до детектора:
   ```kotlin
   val detector = (application as MyApp).backgroundDetector
   ```
3. Виведіть Toast (спливаюче повідомлення) або лог із результатом:
   ```kotlin
   if (detector.isAppInBackground) {
       Toast.makeText(this, "Застосунок у фоні!", Toast.LENGTH_SHORT).show()
   } else {
       Toast.makeText(this, "Застосунок активний!", Toast.LENGTH_SHORT).show()
   }
   ```
   *(Звісно, при натисканні на кнопку застосунок завжди буде активним, але цей код демонструє саму можливість звернення до глобальної утиліти).*

## Частина 4: Тестування та аналіз логів

1. Створіть у проекті **другу Activity** (`SecondActivity`) з кнопкою для повернення назад. 
2. Зробіть так, щоб з `MainActivity` можна було перейти на `SecondActivity`.
3. Запустіть програму та відкрийте **Logcat**.
4. Проробіть наступні кроки і проаналізуйте логи вашого `BackgroundDetector`:
   * **Запуск:** відкрилася `MainActivity` (лічильник = 1).
   * **Перехід:** ви натиснули кнопку, щоб відкрити `SecondActivity` (як змінився лічильник під час переходу? Чи падав він до нуля?).
   * **Згортання:** натисніть кнопку Home на телефоні. Лічильник має впасти до нуля, і ви повинні побачити в логах, що застосунок перейшов у фон.
   * **Відновлення:** відкрийте застосунок знову. Лічильник має стати `1`.
