# Завдання: Симулятор завантаження файлів на Kotlin Flow та MVVM

## Мета завдання
Опанувати практичне використання **холодних реактивних потоків `Kotlin Flow`** у поєднанні з архітектурою **MVVM**: навчитися створювати `Flow` за допомогою білдера `flow { emit(...) }`, керувати потоками виконання через `flowOn(Dispatchers.IO)`, обробляти завершення через `onCompletion`, а також оновлювати `ProgressBar` та UI в реальному часі без блокування екрану.

---

## Опис та вимоги до інтерфейсу застосунку

На екрані застосунку знаходяться:
1. **Кнопка "Скачати файл"** (`btnDownload`).
2. **Кнопка "Скасувати"** (`btnCancel`).
3. **ProgressBar** (`progressBar`) із діапазоном від 0 до 100.
4. **TextView статусу** (`tvStatus`), який показує поточний відсоток завантаження та стан (наприклад, *"Завантаження: 45%"*, *"Файл успішно скачано!"* або *"Завантаження скасовано"*).

---

## Вимоги до архітектури та Kotlin Flow

### 1. Шар Model (`FileRepository`):
* Створіть метод `downloadFile(): Flow<Int>`, який повертає холодний потік значень відсотків від `0` до `100`.
* Усередині білдера `flow { ... }` реалізуйте цикл (наприклад, від 0 до 100 з кроком у 5% або 10%).
* Між емітами затримуйте виконання через `delay(150)` (імітація мережевого запиту).
* Використайте оператор **`flowOn(Dispatchers.IO)`**, щоб завантаження гарантовано виконувалося у фоновому потоці `IO`.

### 2. Шар ViewModel (`DownloadViewModel`):
* `DownloadViewModel` керує запуском та скасуванням корутини завантаження.
* Зберігайте посилання на потік/корутину (`downloadJob: Job?`), щоб мати можливість скасувати завантаження при натисканні кнопки "Скасувати".
* Усі підписки та запуски корутин робіть усередині **`viewModelScope`**.

### 3. Шар View (`MainActivity`):
* `MainActivity` відповідає виключно за відмальовку UI.
* Підпишіться на потік завантаження через `.collect { progress -> ... }`.
* Оновлюйте стан `progressBar.progress = progress` та текст статусу.

## Етапи виконання завдання

### Частина 1: Створення шару Model (`FileRepository`)
1. Створіть клас `FileRepository`.
2. Додайте функцію `downloadFile(): Flow<Int> = flow { ... }`.
3. У циклі від 0 до 100 викликами `emit(progress)` надсилайте поточний відсоток та робіть `delay(150)`.
4. Вкажіть диспатчер виконання через `.flowOn(Dispatchers.IO)`.

---

### Частина 2: Створення шару ViewModel (`DownloadViewModel`)
1. Створіть `DownloadViewModel : ViewModel()`.
2. Додайте інкапсульований `StateFlow` або `LiveData` для збереження стану UI (поточний відсоток та текст статусу).
3. Додайте метод `startDownload()`, який запускає корутину в `viewModelScope.launch` і викликає `fileRepository.downloadFile().collect { ... }`.
4. Використайте оператор **`onCompletion { ... }`** у `Flow` для виявлення того, чи було завантаження завершено успішно, чи воно було скасовано користувачем.
5. Додайте метод `cancelDownload()`, який викликає `downloadJob?.cancel()`.

---

### Частина 3: Збирання даних у View (`MainActivity`) та тестування
1. У `MainActivity` за допомогою `by viewModels()` отримайте екземпляр `DownloadViewModel`.
2. Налаштуйте обробники кліків:
   * Натискання `btnDownload` ➔ викликає `viewModel.startDownload()`.
   * Натискання `btnCancel` ➔ викликає `viewModel.cancelDownload()`.
3. Підпишіться на стан із `ViewModel` та оновлюйте `progressBar` і `tvStatus`.
4. **Проведіть тестування:**
   * Натисніть "Скачати файл" і спостерігайте за плавною анімацією `ProgressBar` від 0% до 100%.
   * Натисніть "Скачати файл", а на 50% натисніть "Скасувати" — переконайтеся, що завантаження зупинилося і статус змінився на *"Завантаження скасовано"*.
   * Натисніть "Скачати файл" і переверніть екран пристрою — переконайтеся, що завантаження продовжується, а новий екран показує актуальний відсоток!

Успіхів! Ви створили сучасний завантажувач файлів на Kotlin Flow!
